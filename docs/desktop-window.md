# 今日任务置顶小窗

## 怎么使用

在支持的桌面浏览器中打开应用，进入「我的一天」，点击「置顶小窗」。小窗中可切换「待完成／已完成」、新增任务、完成任务，或将已完成任务恢复到待完成。无论在哪个窗口完成任务，小窗都会提供最近完成事项的撤销入口。点击右上角返回按钮可回到主页面。

小窗与主页面共用同一份 React 状态和任务仓库，不额外复制账号会话，不通过轮询同步。主页面里的新增、完成等操作也会反映到小窗。写入失败时保留原任务并显示错误。小窗继承主页面实际使用的颜色，并跟随主页面主题变化；不会独立切换深浅色。

底部只保留简洁的同步状态与「使用说明」入口。点击说明可查看窗口关闭规则，再次点击或按 Escape 收起；任务列表较长时在列表区域滚动，不挤走底部操作。

## 外观与右键操作

主界面左侧栏底部的主题按钮可直接循环切换浅色、深色和跟随系统，偏好保存在当前浏览器并同步到小窗。小窗内容区使用主题化右键菜单，可切换视图、操作任务和切换主题。输入框与已选文字保留原生编辑菜单，Shift+右键也可打开浏览器菜单；原生菜单不保证跟随应用配色。[查看主题与菜单说明](theme.md)。

## 它是什么，不是什么

采用浏览器的 Document Picture-in-Picture API。支持该 API 的桌面浏览器会提供置顶窗口，可由用户拖动、调整大小，适合在切换其他应用时查看待办。

- 需要 HTTPS 或 localhost 安全环境，以及用户点击触发。
- 采用能力检测，不将某个浏览器名称当作支持保证；不支持时显示说明，不使用普通弹窗冒充置顶窗口。
- 手机布局不提供此入口。
- 关闭主页面、刷新／离开页面或退出账号后，小窗随之关闭，不是独立桌面程序。
- 网页不能强制固定小窗的屏幕坐标，也不能保证开机自启、桌面嵌入、系统托盘或关闭浏览器后继续运行。
- 若需要这些原生能力，后续应单独评估桌面应用，而不是把现有网页功能描述成完整桌面挂件。

## 安全与验证

仅登录后的工作区或开发演示中提供入口。退出时关闭小窗；请求仍在等待返回时退出，也不会在稍后重新显示旧账号内容。窗口关闭后可重新打开，重复点击只聚焦现有窗口。

测试覆盖主／小窗主题偏好相反时的颜色同步、主题切换、状态页签与键盘操作、跨窗口撤销、失败恢复、底部说明和窄窗布局，以及双向同步、完成／撤销、写入失败、重复打开、关闭／重开、退出清理、等待窗口期间退出、不支持／拒绝请求及移动端隐藏。原生浏览器测试验证实际 API 打开和关闭；自动化不能代替不同操作系统、浏览器版本及真实桌面切换时的人工置顶体验检查。
