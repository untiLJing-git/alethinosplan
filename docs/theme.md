# 外观与小窗右键菜单

## 主界面外观

登录后，在主界面左侧栏底部点击主题按钮，按「浅色 → 深色 → 跟随系统 → 浅色」循环切换，不再展开选项面板。按钮图标与文字表示当前模式，悬停或屏幕阅读器可获得下一次切换的目标。移动端按钮位于屏幕左下角，不占顶部导航位置。手动选择浅／深色后，系统明暗切换不会覆盖它；选择跟随系统才会随系统变化。

偏好以 alethinosplan.theme.v1 存在当前浏览器的 localStorage，不写入账号或 Supabase。刷新、退出／重新登录后继续生效，同源其他标签页通过 storage 事件同步。浏览器不允许保存时，本次选择仍生效，并显示无法保存的说明。

public/theme-init.js 在页面首次绘制前读取有效偏好，React 中的 ThemeProvider 继续处理选择、系统变化和跨标签页更新。登录页同样遵循已经保存的偏好。

## 小窗菜单

在置顶小窗的任务或空白处点击右键，或者在非编辑控件上按 Shift+F10，可打开应用菜单。菜单提供：

- 当前任务的完成／恢复操作（在任务上右键时显示）。
- 查看待完成／已完成、聚焦新增任务输入框。
- 返回主页面、关闭小窗。
- 浅色、深色、跟随系统，与主页面共享同一份偏好。

菜单使用应用自己的颜色与组件，不依赖浏览器原生菜单的配色。支持方向键、Home／End、Esc、点击外部关闭，并在较小窗口中调整位置以避免溢出。

## 原生菜单边界

浏览器自身的右键菜单、标题栏和操作系统窗口装饰不属于应用 DOM，不能保证跟随网页的自定义主题。

为了不损失编辑能力，输入框／文本编辑区域、已选中文字时继续使用原生复制／粘贴菜单；Shift+右键也保留浏览器菜单入口。这些原生区域的实际配色仍取决于浏览器和操作系统。本项目没有通过模拟粘贴或读取剪贴板来替换它们。

## 验证

测试覆盖手动模式与系统模式、刷新持久化、跨标签页同步、存储失败、左下角单按钮位置、键盘循环切换、移动端布局、小窗菜单配色、任务操作、键盘交互、边界定位和原生编辑菜单保留。Pages 验收另行确认主题脚本的返回类型与生产页面的主题恢复。
